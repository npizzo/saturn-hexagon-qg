Prescribed deep flow: four long integrations

Four 1024² QG integrations compare a half-strength deep jet, a full-strength deep jet, a deep central cyclone, and their combination. Each starts from the same upper-layer flow with broadband modes 2–8 (seed 42), deformation radius 3200 km, and convection off, and runs for 3,125,000 s (36.17 Earth days). Compare with the reference broadband run in the formation collection. These are regularized QG analogues of the 2017 shallow-water setup; completion does not establish stability or agreement with Saturn’s observed propagation speed.

These are exploratory simulations, not established Saturn hexagons. Read the initial condition and configuration differences before comparing runs.

How to read the gallery

  • Every image is an actual saved time. Sparse snapshots can show changing structure but do not resolve all motion between frames.
  • Vorticity and speed color scales are shared across this gallery; each run uses its configured science disk.
  • Mode curves describe the measured jet centreline. Tracker gaps remain missing, and complete coverage alone does not guarantee a continuous physical jet.
  • Pattern speeds need a declared rotation frame and a valid coherent signal. This gallery does not fit drift from late rolled-up fields.
  • Comparisons should use matched physical times and account for all configuration differences. Completion is not timestep, spatial or physical validation.
